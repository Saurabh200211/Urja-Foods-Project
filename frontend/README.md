# Urja Foods Premium Footer

React + Vite + Tailwind CSS + Lucide React.

## Run

1. Install Node.js LTS (Node 22.x works well).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build

Run `npm run build`.

## Customize

Edit `src/components/UrjaFooter.jsx` and replace the placeholder phone, email, location, links, and social URLs.
